# Примерка дверей в AR

Веб-приложение для примерки дверей через дополненную реальность.
Работает в Safari на iPhone/iPad — открывается по ссылке, без установки из App Store.

## Как это работает

- 3D-превью двери в браузере (крутить пальцем).
- Кнопка **«Примерить в AR»** → камера → ставишь дверь в проём, двигаешь/крутишь пальцами.
- Модель фиксируется в пространстве: можно обойти, посмотреть сбоку, оценить в натуральную величину.
- На iPhone 14 Pro привязка особенно стабильная за счёт LiDAR.

Основа — бесплатная библиотека [`<model-viewer>`](https://modelviewer.dev/) от Google,
на iOS использующая штатный Apple **AR Quick Look**.

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | разметка страницы |
| `styles.css` | оформление (светлая/тёмная тема) |
| `app.js` | логика каталога, цвета, размера, AR |
| `gen-manifest.mjs` | генератор каталога по содержимому `models/` |
| `models/` | сюда кладёшь `.glb` / `.usdz` / превью; здесь же `manifest.json` |

Каталог **динамический**: приложение читает `models/manifest.json`, который
генерируется скриптом по файлам в папке. Список дверей вручную нигде не правится.

## Добавить свою дверь

1. Положи в `models/`:
   - `имя.glb` — для превью в браузере (обязательно);
   - `имя.usdz` — для AR на iPhone (то же имя; без него превью работает, AR — нет);
   - `имя.jpg/.png/.webp` — превью для каталога (необязательно).
2. Перегенерируй каталог:

   ```bash
   node gen-manifest.mjs
   ```
3. Обнови страницу.

Название берётся из имени файла. Чтобы задать своё название и номинальные размеры —
создай `models/labels.json`:

```json
{
  "wooden_door_v3": { "name": "Дуб Классик", "width": 900, "height": 2100 }
}
```

> Единицы и ориентация модели значения не имеют: приложение само измеряет
> габариты, ставит дверь вертикально и приводит к заданным Ш×В (в т.ч. в AR).

## Где взять `.usdz`

- **Reality Converter** (Apple, бесплатно, macOS) — перетащил `.glb`, получил `.usdz`.
- Онлайн-конвертеры glTF → USDZ.
- Многие 3D-редакторы (Blender + плагины) экспортируют оба формата.

## Как выложить (бесплатно)

AR Quick Look требует **HTTPS**. Проще всего — GitHub Pages:

1. Создай репозиторий, залей все файлы.
2. **Settings → Pages** → Source: ветка `main`, папка `/root`.
3. Открой выданную `https://…github.io/…` ссылку в **Safari на iPhone**.

Локальная проверка с телефона: `npx serve` + туннель `ngrok http 3000`.

## Ограничения

- Автоопределение проёма (по LiDAR) в бесплатном web невозможно — это только нативный ARKit.
  Здесь пользователь совмещает дверь с проёмом вручную.
- Рисование AR-рамки по тапам доступно только в платном 8th Wall или нативном приложении.
