# 🚪 Примерка дверей в AR

**Примеряю двери на iPhone в дополненной реальности — прямо в браузере.**

<sub>Личный проект · без App Store · без сборки и зависимостей</sub>

</div>

---

Небольшое приложение **для себя**. Не коммерческий продукт — просто удобный способ
посмотреть, как дверь встанет в реальном проёме: открываешь ссылку в Safari на iPhone,
ставишь модель в интерьер и оцениваешь в натуральную величину. Устанавливать ничего
не нужно.

Под капотом — бесплатная библиотека [`<model-viewer>`](https://modelviewer.dev/) от
Google, которая на iOS запускает штатный Apple **AR Quick Look**.

## ✨ Как это работает

- **3D-превью** двери в браузере — крутится пальцем.
- Кнопка **«Примерить в AR»** → камера → ставишь дверь в проём, двигаешь и крутишь пальцами.
- Модель **фиксируется в пространстве**: можно обойти, посмотреть сбоку, оценить размер вживую.
- На **iPhone 14 Pro** привязка особенно стабильная — за счёт LiDAR.

## 🚀 Быстрый старт

```bash
# 1. Положи модель в models/  (см. «Добавить свою дверь»)
# 2. Собери каталог
node gen-manifest.mjs
# 3. Открой index.html по HTTPS в Safari на iPhone
```

> [!NOTE]
> AR-режим требует **HTTPS**. Локально с телефона: `npx serve` + туннель `ngrok http 3000`.
> Постоянный хостинг — см. раздел [«Публикация»](#-публикация).

## 📁 Структура

| Файл | Назначение |
|------|-----------|
| `index.html` | разметка страницы |
| `styles.css` | оформление (светлая / тёмная тема) |
| `app.js` | логика каталога, цвета, размера, AR |
| `gen-manifest.mjs` | генератор каталога по содержимому `models/` |
| `models/` | сюда кладёшь `.glb` / `.usdz` / превью; здесь же `manifest.json` |

Каталог **динамический**: приложение читает `models/manifest.json`, который генерируется
скриптом по файлам в папке. Список дверей вручную нигде не правится.

## ➕ Добавить свою дверь

1. Положи в `models/`:
   | Файл | Для чего | Обязательно |
   |------|----------|:-----------:|
   | `имя.glb` | превью в браузере | ✅ |
   | `имя.usdz` | AR на iPhone (то же имя) | ⚠️ без него AR не работает |
   | `имя.jpg` / `.png` / `.webp` | превью в каталоге | — |
2. Перегенерируй каталог:
   ```bash
   node gen-manifest.mjs
   ```
3. Обнови страницу.

Название берётся из имени файла. Чтобы задать своё имя и номинальные размеры — создай
`models/labels.json`:

```json
{
  "wooden_door_v3": { "name": "Дуб Классик", "width": 900, "height": 2100 }
}
```

> [!TIP]
> Единицы и ориентация модели значения не имеют: приложение само измеряет габариты,
> ставит дверь вертикально и приводит к заданным **Ш × В** (в том числе в AR).

## 🔁 Где взять `.usdz`

- **Reality Converter** (Apple, бесплатно, macOS) — перетащил `.glb`, получил `.usdz`.
- Онлайн-конвертеры glTF → USDZ.
- Многие 3D-редакторы (Blender + плагины) экспортируют оба формата.

## 🌐 Публикация

AR Quick Look требует **HTTPS**. Проще всего — GitHub Pages:

1. Создай репозиторий, залей все файлы.
2. **Settings → Pages** → Source: ветка `main`, папка `/root`.
3. Открой выданную `https://…github.io/…` ссылку в **Safari на iPhone**.

## ⚠️ Ограничения

- **Автоопределение проёма** (по LiDAR) в бесплатном web невозможно — это только нативный
  ARKit. Здесь дверь совмещается с проёмом вручную.
- **Рисование AR-рамки по тапам** доступно только в платном 8th Wall или нативном приложении.
